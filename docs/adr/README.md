# ADR transversaux — Entraînement

Ce dossier reçoit uniquement les décisions structurantes concernant les modules communs ou plusieurs jeux. Une décision propre à un jeu va dans `docs/games/<id>/adr/`, uniquement si elle mérite un ADR.

Conventions : `0001-titre-court.md`, numéro croissant dans son dossier, date, portée, statut **Proposé**, **Accepté** ou **Remplacé**, puis sections **Contexte**, **Options envisagées**, **Décision** et **Conséquences**.

Un ADR accepté reste un témoignage de la décision prise. Lorsqu'elle change, ajouter un ADR successeur et indiquer « Remplacé par » dans l'ancien ; actualiser aussi l'architecture qui décrit toujours la situation présente.
