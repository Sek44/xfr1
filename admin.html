Accès réservé

Difficultés et maîtrise

La difficulté est commune à tous les joueurs et doit être publiée sur GitHub. La maîtrise est locale à cet appareil : « Auto » réactive son calcul à partir des exercices.

Modifier dans GitHub

Pour une connexion GitHub classique, utilisez « Modifier dans GitHub » après avoir copié la configuration. Pour enregistrer directement depuis cette page, saisissez un jeton personnel limité au dépôt xfr1 : il est utilisé une seule fois et n’est jamais conservé.

Bonus de temps ponctuel

Le bonus est ajouté en secondes aux crédits quotidiens partagés avec GMR, sans ajouter de score ni d’exercice. Il expire avec les crédits du jour.

Données locales du joueur

Ces données appartiennent au navigateur actuel. Elles ne sont pas sauvegardées sur GitHub et ne sont pas synchronisées avec d’autres appareils.
